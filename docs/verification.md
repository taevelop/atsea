# At Sea 3D 검증 기록

검증 기준은 비교용 원본 `atsea2d/index.html` v4.5.0입니다. 원본 파일은 변경하지 않습니다.

## 실행 방법

```powershell
npm test
npm run dev
# 개발 서버가 http://localhost:5173 에서 준비된 별도 터미널에서
npm run test:e2e
```

E2E는 설치된 Microsoft Edge를 사용합니다. 다른 Chromium 설치를 사용하려면 `PLAYWRIGHT_CHANNEL`을 지정합니다. 서버가 다른 주소를 사용하면 `PLAYWRIGHT_BASE_URL`을 지정합니다. 테스트 서버는 자동으로 시작하거나 종료하지 않습니다. `playwright-report/index.html`에서 결과와 첨부를 열 수 있습니다.

## 시각 증거와 발견한 회귀

초기 기능 테스트는 통과했으나 해저 스크린샷에서 빈 3D 프레임이 발견되었습니다. 자동 해상도 조정이 그리기 버퍼를 비우던 순서를 수정한 후 최종 테스트를 다시 실행했습니다. 수중 영역만 검사하는 픽셀 회귀 가드를 추가해 HTML 조작부가 남아 있어도 빈 캔버스는 통과하지 못하게 했습니다. 정상 표층은 6,903색, 중층은 16,019색이었던 반면 발견 당시 빈 해저 프레임은 1색이었고, 최종 양쪽 화면의 모든 수심은 가드를 통과했습니다.

## 성능 측정과 한계

자동화 환경은 **Windows headless Microsoft Edge 152 + ANGLE SwiftShader 소프트웨어 WebGL**입니다. 기본 개체 수, 해저 1,500m에서 약 4초간 rAF 프레임을 측정했습니다. 페이지 DPR은 1이며 자동 품질 조정 후 렌더링 배율은 두 경우 모두 0.65였습니다.

### 상단 제목과 전환 버튼 위치 후속 검증

실제 표시 모드에 따라 상단 제목과 브라우저 탭 제목을 2D의 `ASCII Tropical Sea`, 3D의 `Animated Tropical Sea`로 갱신합니다. 전환 버튼은 제목 바로 오른쪽에 두며, 배경화면에서는 제목·전환 버튼·도구·종료 버튼이 겹치지 않게 표시됩니다. 320px 화면의 두 모드를 agent-browser 캡처로 직접 확인했습니다.

린트, 단위 63개, 웹 빌드, 단일 HTML 빌드 및 오프라인 8개 검사를 통과했습니다. 웹은 데스크톱·모바일의 기존 레이아웃, 반복 전환, 로딩 중 선택, 배경화면 조작 등 변경 영역 8개 시나리오를 검증했습니다. 초기 실행에서는 개발 서버가 단일 HTML 빌드와 테스트 캡처 HTML을 변경 파일로 감지해 페이지를 새로고침한 로그가 있었고, 모델 준비 시간 초과 3건이 발생했습니다. 빌드 종료 후 테스트 출력 경로를 `.cache/`로 옮겨 같은 코드로 해당 시나리오를 단독 재실행했으며, 데스크톱·모바일 4개 모두 통과했습니다. 재검증 결과는 `.cache/title-recheck/`에 있습니다.

### 단일 모드 전환 버튼 후속 검증

상단의 두 선택 버튼을 WATER·언어 버튼과 같은 공통 스타일의 단일 버튼으로 바꿨습니다. 2D에서는 `3D`, 3D에서는 `2D`를 표시하며, 3D 준비 중 클릭은 전환 취소, 실패 후 클릭은 재시도로 처리합니다. 제목 오른쪽 위치와 모드별 제목, 한국어·영어 접근성 설명을 유지합니다.

린트와 웹·단일 HTML 빌드, 변경 영역 웹 E2E 14개, 오프라인 E2E 8개가 모두 통과했습니다. 한 버튼으로 반복 전환·낚시·도감·기록 공유·마지막 선택·로딩 취소·오류 재시도·배경화면을 검증했으며, 오프라인에서는 한 개의 버튼과 모드별 문구, 저장 복원 및 한국어 설명도 확인했습니다. agent-browser로 데스크톱 3D와 모바일 ASCII의 버튼 모양을 직접 확인했습니다. 웹 결과는 `.cache/button-checks/`, 오프라인 보고서는 `playwright-report-single/`에 있습니다.

### 2.0.0 릴리스 버전 확인

`package.json`, 잠금 파일의 루트 버전, HTML 메타데이터·도움말, 웹앱 매니페스트를 `2.0.0`으로 맞추고 README에 릴리스 기능과 사용법을 정리했습니다. 린트, 단위 63개, 웹 빌드와 단일 HTML 빌드를 다시 통과했으며, 생성된 HTML·매니페스트의 버전 일치도 확인했습니다. 기능 코드에는 추가 변경이 없어 위의 단일 버튼 웹 14개·오프라인 8개 결과를 유지합니다.
