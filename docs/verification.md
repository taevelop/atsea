# At Sea 3D 검증 기록

검증 기준은 비교용 원본 `atsea2d/index.html` v4.5.0입니다. 원본 파일은 변경하지 않습니다.

## 실행 방법

```powershell
npm test
npm run dev
# 개발 서버가 http://localhost:5173 에서 준비된 별도 터미널에서
npm run test:e2e
```

E2E는 설치된 Microsoft Edge를 사용합니다. 다른 Chromium 설치를 사용하려면 `PLAYWRIGHT_CHANNEL`을 지정합니다. 서버가 다른 주소를 사용하면 `PLAYWRIGHT_BASE_URL`을 지정합니다. 테스트 서버는 자동으로 시작하거나 종료하지 않습니다. `playwright-report/index.html`에서 결과와 첨부를 열 수 있습니다.

## 시각 증거와 발견한 회귀

초기 기능 테스트는 통과했으나 해저 스크린샷에서 빈 3D 프레임이 발견되었습니다. 자동 해상도 조정이 그리기 버퍼를 비우던 순서를 수정한 후 최종 테스트를 다시 실행했습니다. 수중 영역만 검사하는 픽셀 회귀 가드를 추가해 HTML 조작부가 남아 있어도 빈 캔버스는 통과하지 못하게 했습니다. 정상 표층은 6,903색, 중층은 16,019색이었던 반면 발견 당시 빈 해저 프레임은 1색이었고, 최종 양쪽 화면의 모든 수심은 가드를 통과했습니다.

최종 해저 스크린샷을 직접 확인해 아귀·문어·발광어, 해저 지형·바위·산호·해초·불가사리와 기존 조작부가 보이는 것을 확인했습니다. 전체 20개 기능 검증 보고서와 화면은 로컬의 `playwright-report/`, `test-results/`에 보존했습니다. 마지막 6개 검증은 로컬의 `playwright-report-targeted/`, `test-results-targeted/`에 분리했습니다. 이 실행 보고서 폴더들은 Git에 포함하지 않으며, 테스트를 다시 실행하면 생성됩니다. 마지막 렌더러의 표층·중층·해저 화면과 성능 JSON은 `docs/evidence/`에 별도로 포함했습니다. 아래 링크는 저장소에서 열 수 있는 증거입니다.

## 성능 측정과 한계

자동화 환경은 **Windows headless Microsoft Edge 152 + ANGLE SwiftShader 소프트웨어 WebGL**입니다. 기본 개체 수, 해저 1,500m에서 약 4초간 rAF 프레임을 측정했습니다. 페이지 DPR은 1이며 자동 품질 조정 후 렌더링 배율은 두 경우 모두 0.65였습니다.

| 소프트웨어 렌더링 뷰포트 | FPS | P95 프레임 시간 | 보이는 모델 | Draw calls | Triangles |
|---|---:|---:|---:|---:|---:|
| 데스크톱 1440×960 | 8.1 | 132.0ms | 102 | 391 | 235,010 |
| 모바일 에뮬레이션 390×844 | 19.3 | 62.5ms | 38 | 151 | 89,892 |

이 소프트웨어 렌더링 측정에서는 데스크톱 60fps / 모바일 30fps 목표에 도달하지 않았습니다. 390×844 프로젝트는 터치와 뷰포트를 에뮬레이션하며 실제 모바일 GPU 성능을 증명하지 않습니다. 아래 하드웨어 가속 결과와 구분해서 해석해야 합니다. 실기기 모바일 30fps 달성 여부는 실제 기기에서 별도 측정해야 합니다.

### 하드웨어 가속 별도 측정

2026-09-08 11:50 KST, 다른 브라우저 검증을 종료한 뒤 **Microsoft Edge 152 / NVIDIA GeForce RTX 5050 Laptop GPU / ANGLE Direct3D 11** 환경에서 기본 개체 수의 해저를 약 7초간 측정했습니다. 뷰포트는 1440×960, 페이지 DPR 및 실제 렌더링 배율은 모두 1입니다. [측정 원본 JSON](evidence/gpu-performance.json)에 GPU 문자열과 전체 상태를 보존했습니다.

| FPS | P95 프레임 시간 | 보이는 모델 | Draw calls | Triangles |
|---:|---:|---:|---:|---:|
| 56.4 | 18.2ms | 92 | 375 | 234,164 |

이 환경의 해저에서는 60fps 목표에 근접했습니다. 측정 시간과 기기가 제한되어 모든 데스크톱에서 60fps를 보장하는 결과는 아니며, 실제 모바일 기기 성능은 검증하지 않았습니다.

원본의 배경화면 모드는 세션 내 화면 상태이며 별도 저장 키가 없습니다. 배경화면 전환 시 보던 수심과 종료 경로를 검증했으며, 재접속 저장 호환은 원래 저장되는 언어·조작부·슬라이더·수집 기록을 대상으로 합니다.
