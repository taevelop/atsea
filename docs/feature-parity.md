## 구현 경계와 보완

- 게임 규칙은 `src/game/ocean.js`, 수집·칭호·트로피 조건은 `src/game/progression.js`, 저장 읽기는 `src/game/storage.js`에 분리했습니다.
- 생물 논리 폭·높이는 기존 도안에서 추출한 `DATA.sizes`의 숫자입니다. 게임 모듈에 ASCII 도안이나 그리기 코드는 없습니다. 모델과 충돌 판정을 독립적으로 조정할 수 있습니다.
- `src/main.js`는 기존 UI 조작과 알림을 연결하고 `SeaRenderer`에 게임 상태를 전달합니다. 도감과 포획 알림은 동일 GLB 모델의 정적 이미지로 바뀝니다.
- 잠수함의 `y`와 `yf`를 함께 설정하여 3D 보간 좌표에서도 사용자가 선택한 수심을 지킵니다.
- 자동 포식·자동 낚시의 예약 시간도 일시정지 시계에 묶고, 새 바다의 예약은 현재 시계 기준으로 시작합니다. 일시정지/리사이즈 때문에 예약이 갑자기 만료되지 않습니다.
- 로딩 진행 표시, 모델/렌더 오류 안내 및 재시도, WebGL context 복구, 페이지 종료 시 GPU 정리를 추가합니다. 재시도나 context 손실 뒤 늦게 완료된 이전 로딩은 새 상태를 덮어쓰지 못합니다.
- 도감은 열릴 때 닫기 버튼에 초점을 두고 Tab을 내부로 제한합니다. 닫으면 이전 초점으로 돌아가며, 종 카드는 Enter/Space로 해당 수심에 이동합니다. 도감·트로피 위에서 게임 조작 키가 배경 동작을 바꾸지 않습니다.
- 저장은 origin 단위입니다. 기존 서비스와 같은 출처에 배포할 때 저장 기록이 이어지고, localhost는 별도 기록을 사용합니다.

## 개발 검증 API

`import.meta.env.DEV` 또는 `VITE_E2E=true`일 때만 `window.__ATSEA__`를 노출합니다. 일반 프로덕션 빌드에는 이 인터페이스가 없습니다.

- `getState()` / `snapshot()`: 직렬화 가능한 ready/failed, cam/camTarget/depth/rows/cols/depthFraction, paused/waterOn/redTide/clock/lang, counts, 모든 기록, 낚싯줄 상태, 잠수함 수, 렌더 통계를 반환합니다.
- `diveToFraction(f)`: 0~1의 목표 수심을 설정합니다. 카메라는 정상 관성을 따라갑니다.
- `setPaused(bool)`, `restock()`, `setLang('en'|'ko')`, `castRod()`, `toggleSub()`, `scatterBait()`: 실제 UI와 같은 처리 함수를 호출합니다.
- `getOcean()`: 낚시/희귀종 테스트에 한해 순수 시뮬레이션 인스턴스를 제공합니다.
- `step(milliseconds)`: 최대 50ms 단위로 프레임을 진행합니다. 일시정지를 존중하며 UI·도감 기록은 정상 처리합니다.
- `recordCatch({kind,shapeIndex,rare})`, `sightRareShark()`: 희귀 확률에 의존하지 않고 수집/칭호 화면을 검증합니다.

검증 도구는 Vitest와 Playwright이며 실제 실행 결과와 성능 측정 환경은 검증 보고서에 기록합니다. 기능 기준표의 항목은 검증 전 통과를 의미하지 않습니다.
